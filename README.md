# Boekenbos

De voorbeeldcode van het project dat je bouwt in de Laravel-lessen van **Lantaarnbos**.

Elke les heeft een eigen tag, zoals `les-4-1-1` of `les-4-2-3`. Kies de tag bovenaan bij "Switch branches/tags" om de code te zien zoals ze er na die les uitziet. Zo kun je je eigen project vergelijken als je vastzit.
